The Tiny Exhibit is a Chrome extension that turns a captioned YouTube video into source-backed questions and one saved takeaway. On first use, the extension explains why it reads the video's transcript and waits for the user to continue.

## Data processing

The extension reads the active YouTube page's video metadata and rendered transcript when the user opens the side panel. Transcript processing happens locally in Chrome. Transcript text is not uploaded, sold, shared, or sent to an AI service.

The extension does not use analytics, advertising trackers, remote code, or an external application server.

## Data stored on the device

When a user chooses to save a takeaway, the extension stores:

- the YouTube video ID, title, channel, and URL;
- the user's takeaway;
- the completion date.

The transcript and quiz answers are not saved after the side panel is closed. Users can edit or remove an individual saved takeaway from the library. Chrome clears the extension's local storage when the extension is removed.

## Permissions

- **activeTab** lets the extension work with the YouTube tab the user selected.
- **scripting** installs the packaged YouTube transcript adapter after the user opens the extension.
- **sidePanel** displays the learning interface beside the video.
- **storage** saves takeaways locally on the user's device.

The extension does not request broad host permissions.

## Limited use

Information accessed through Chrome permissions is used only to provide the extension's visible learning features. The Tiny Exhibit does not transfer this information to third parties, use it for advertising or lending decisions, or allow humans to read it. Its use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
